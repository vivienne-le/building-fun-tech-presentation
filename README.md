# Building fun tech with Vivi

My XLB (Experience Lab B) Show & Tell at THUAS, November 2026. Client: Paul Kuijpers, THUAS Makerspace.

The whole presentation is one self-contained file, `index.html`. Every image and video is built into it, so it works offline.

## View it

Download `index.html` and open it in any browser, or turn on GitHub Pages for this repo (Settings → Pages → deploy from the `main` branch) to get a link.

| Key | Does |
| --- | --- |
| → or Space, or click the right side | next slide |
| ← or click the left side | previous slide |
| F | full screen |
| N | speaker notes |
| ? | show the keys |

Sound on the high-voltage converter clip plays once you've clicked or pressed a key on the page.

## What's in it

- **ClipStar**, my digital hairclip: an M5Stack AtomS3R that counts shots when you tilt your head back, with modes you switch from your phone, in a 3D-printed case
- **Bello Terminal**, a retro messaging terminal with a mood-reading robot, including a live demo loop
- **Side quests**: Gridfinity bins for my electronics, and a high-voltage converter
- **IEEE UCSC**: the student branch website I'm designing, plus an NFC officer-card idea
- **My portfolio**: [vivienne-le.vercel.app](https://vivienne-le.vercel.app/)
